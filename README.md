# FitLog

FitLog is a workout discovery and planning app. Browse exercises, view their details, and organize workouts into a daily plan or a saved list.

## Technologies

- Next.js 16 with the App Router
- React 19
- Tailwind CSS 4
- daisyUI
- React Hot Toast
- FitLog workout API

## Key Features

1. **Workout library** — Browse a collection of exercises with images, descriptions, equipment, difficulty, and stats.
2. **Workout details** — Open an exercise to see its full information and instructions.
3. **Today's plan** — Add exercises to a daily workout list and see its exercise, duration, and calorie totals.
4. **Saved workouts** — Keep a separate list of exercises to revisit later.
5. **Sort and manage lists** — Sort plan and saved workouts by duration, calories, or rating, and receive toast notifications for actions.

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
